Mentions légales

Informations légales, confidentialité et conditions d'utilisation de CodeHub.

Éditeur du site

CodeHub est un projet personnel créé et maintenu par Zeryxx, destiné principalement à un usage entre amis.

Contact : Zeryxx

Hébergement

Le site est hébergé avec GitHub Pages.

GitHub peut traiter certaines données techniques liées à la consultation du site, notamment les adresses IP, conformément à ses propres règles de confidentialité.

Propriété intellectuelle

Les éléments originaux de CodeHub appartiennent à leurs auteurs respectifs. Les personnes qui ajoutent des scripts doivent avoir les droits nécessaires pour les partager.

Contenu publié

CodeHub est une bibliothèque de scripts destinée à un cercle d'amis. Ne publiez pas de mots de passe, clés API, tokens, données personnelles ou autres informations confidentielles.

Si un contenu doit être retiré ou signalé, contactez directement Zeryxx.

Données personnelles

CodeHub ne demande pas de compte utilisateur et ne contient pas de formulaire destiné à collecter volontairement des données personnelles.

Des données techniques peuvent néanmoins être traitées par GitHub Pages lors de la consultation du site. Pour les détails concernant ces traitements, consultez la politique de confidentialité de GitHub.

Cookies et traceurs

CodeHub n'utilise pas volontairement de cookies publicitaires ou de suivi pour son fonctionnement.

Conditions d'utilisation

En utilisant CodeHub, vous vous engagez à ne pas publier de contenu illicite, de données personnelles d'autrui, de secrets, de mots de passe, de clés API ou de contenu que vous n'avez pas le droit de partager.

Les scripts peuvent contenir du code fourni par leurs auteurs. Vérifiez toujours un script avant de l'exécuter.
